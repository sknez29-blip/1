# Вась, хрумни!

Тапалка про Васю, хрумку и сушняк. Открой `index.html` в браузере.

- Тапай по Васе: он хрумкает и приносит хрумки.
- Каждый хрум добавляет сушняк. Выше 50% хрумки идут хуже, на 100% Вася засыхает на 4 секунды.
- Запивай водой, квасом или огуречным рассолом (рассол ещё и даёт ×2 на 15 секунд).
- Прокачка: пачка побольше, сухарики с чесноком, бабушка с пакетом, кореш Петя, кулер на кухне.

- Нефоры: панк Шнурок, эмо Кирюша, хиппи Ромашка, гот Мрак и металлист Борода. У каждого своя фишка (доход в секунду, крит-хрум ×5, дешёвые напитки, меньше сушняка), а позванные тусят рядом с Васей.
- Разделы переключаются вкладками внизу экрана: Вася, Прокачка, Нефоры, Ещё.

Прогресс сохраняется в браузере.
